# 프로그램 전체 기능 및 재실행 증거

원본 상태 파일을 훼손하지 않도록 `main.py`와 `state.json`을 임시 디렉터리에 복사해 실행했다.

## 1차 실행 결과

```text
📂 저장된 데이터를 불러왔습니다. (퀴즈 5개, 최고 점수 기록 없음)
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료

📋 등록된 퀴즈 목록 (총 5개)
📌 새로운 퀴즈를 추가합니다.
✅ 퀴즈가 추가되고 저장되었습니다!
📝 퀴즈를 시작합니다! (총 6문제)
[문제 6] 추가된 증거 문제
🏆 결과: 6문제 중 6문제 정답! (100점)
🎉 새로운 최고 점수입니다!
🏆 최고 점수: 100점 (6문제 중 6문제 정답)
👋 게임을 종료합니다.
```

## 2차 실행 결과

```text
📂 저장된 데이터를 불러왔습니다. (퀴즈 6개, 최고 점수 100)
📋 등록된 퀴즈 목록 (총 6개)
[6] 추가된 증거 문제
🏆 최고 점수: 100점 (6문제 중 6문제 정답)
👋 게임을 종료합니다.
```

서로 다른 두 번째 프로세스가 추가된 문제와 최고 점수를 다시 불러왔으므로 영속성이 확인된다.
